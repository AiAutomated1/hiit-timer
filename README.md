# HIIT Timer

A personal interval timer for F45-style station workouts. Plain HTML/CSS/JS, installable to the iPhone home screen, works offline.

**Install:** open the GitHub Pages URL in Safari → Share → Add to Home Screen.

**Release an update:** edit `index.html`, bump `CACHE` in `sw.js` and `APP_VERSION` in `index.html`, push. The installed app picks it up on the next launch with signal (open it twice to see it).
